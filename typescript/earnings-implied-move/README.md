# TypeScript Recipe: Earnings Implied Move

Use this recipe when you want a lightweight Node script for ATM straddle implied move estimation.

## Prerequisites

- Node 18+
- `CUTEMARKETS_API_KEY=cm_...`
- `npm install` from the cookbook root

## Run

```bash
npm install
npm run ts:earnings-implied-move
```
