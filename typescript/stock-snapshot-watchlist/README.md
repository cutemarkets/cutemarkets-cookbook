# TypeScript Recipe: Stock Snapshot Watchlist

Use this recipe when you want a small Node script that pulls current stock snapshots and a short daily-bar window.

## Prerequisites

- Node 18+
- `CUTEMARKETS_STOCKS_API_KEY=cm_...` or `CUTEMARKETS_API_KEY=cm_...`
- `npm install` from the cookbook root

## Run

```bash
npm run ts:stock-snapshot-watchlist
```
