# TypeScript Recipe: Options Chain Scanner

This recipe mirrors the Python chain-scanner workflow for Node and server-side JavaScript.

## Prerequisites

- Node 18+
- `CUTEMARKETS_API_KEY=cm_...`
- `npm install` from the cookbook root

## Run

```bash
npm install
npm run ts:options-chain-scanner
```
